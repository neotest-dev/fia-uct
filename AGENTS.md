# Project Instructions

## Language

- Siempre responde en español.
- Todo el código debe estar en inglés.
- Los nombres de variables, funciones, clases y archivos deben permanecer en inglés.
- Explica las decisiones técnicas en español.

## Development

- Prioriza soluciones listas para producción.
- Aplica SOLID, Clean Architecture y Clean Code.
- No refactorices código que no se haya solicitado.
- Modifica únicamente los archivos necesarios.
